隱私權政策

適用：便籤／常用語工具（https://ke-ro-ro.github.io/Post-1024/）
生效日期：2026 年 9 月 27 日

1. 這是什麼

這是個人提供的免費網頁工具，用來整理便籤、常用語與連結。沒有後端伺服器，也沒有公司在經營；整個工具就是放在 GitHub Pages 上的網頁，在你的瀏覽器裡執行。

2. 我們不收集你的資料

你在工具裡輸入的內容只會放在兩個地方：

  • 瀏覽器這個分頁的暫存區：關掉分頁或登出就清除。
  • 你自己的 Google 雲端硬碟中，這個工具專屬的隱藏資料夾（只有在你登入 Google 並使用雲端同步時）。

工具的提供者看不到任何使用者的內容，也沒有地方可以收到這些內容。不同使用者之間的資料也互相看不到。

3. 向 Google 要求的權限與用途

  • 存取「這個應用程式專屬的雲端硬碟資料夾」（https://www.googleapis.com/auth/drive.appdata）：只用來存放與讀取工具自己的同步檔。碰不到你雲端硬碟裡的其他檔案，這個資料夾在雲端硬碟畫面上也看不到。
  • 電子郵件地址（email）：只用來在同步面板上顯示目前登入的是哪個帳號，不會傳到任何其他地方。

登入後取得的存取憑證只放在瀏覽器的記憶體裡，不寫進瀏覽器儲存空間，關掉分頁就消失。

4. 不分享、不出售

這個工具不會把從 Google API 取得的資料分享、轉交或出售給任何人，也不用於廣告。

本工具使用從 Google API 取得的資訊時，遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定（Limited Use requirements）。

5. Cookie、追蹤與第三方

  • 沒有分析追蹤、沒有廣告，工具本身不設定任何 cookie。
  • 唯一載入的外部程式是 Google 登入服務（accounts.google.com）；雲端同步直接連線 Google 的 API（www.googleapis.com）。其他所有程式都放在本網站上。
  • 網站由 GitHub Pages 代管，GitHub 可能依其自身政策記錄一般的連線資訊（例如 IP 位址），這部分不在本工具控制範圍內。

6. 如何刪除你的資料

  • 瀏覽器裡的資料：在工具裡登出，或直接關掉分頁。
  • 雲端硬碟裡的同步檔：開啟 Google 雲端硬碟 → 右上角「設定」→「管理應用程式」→ 找到這個工具 →「選項」→「刪除隱藏的應用程式資料」。
  • 取消授權：到 Google 帳戶 →「安全性」→「具有帳戶存取權的第三方應用程式」，移除這個工具。

7. 政策更新

這份政策如有修改，會更新本頁上方的生效日期。

8. 聯絡方式

有任何問題請寄信到 sticky-notes-help@googlegroups.com。
