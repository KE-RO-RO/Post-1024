# 便籤／常用語工具 — 瀏覽器版

對應規格書 `便籤工具_瀏覽器版_功能規格書_v4.22.md`。

自用的常用語／便籤工具。核心是把常用的句子存起來，點一下複製到剪貼簿，切到要用的視窗按 Ctrl+V 貼上。

## 怎麼放上 GitHub Pages

1. 在 GitHub 建一個新的儲存庫，例如 `sticky-notes`，選 **Public**
2. 把這個資料夾裡的**所有內容**（`index.html`、`css/`、`js/`、`README.md`）上傳進去
   - 網頁版做法：儲存庫頁面 → `Add file` → `Upload files` → 把檔案拖進去 → `Commit changes`
   - **注意要保留資料夾結構**，`css` 和 `js` 兩個資料夾要在，不能把檔案全部攤平
3. 儲存庫 → `Settings` → 左邊 `Pages`
4. `Source` 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)` → `Save`
5. 等一兩分鐘，頁面上方會出現網址，格式是 `https://你的帳號.github.io/sticky-notes/`

之後每次更新，就是把新檔案重新上傳覆蓋，幾秒鐘生效。

> **這個網址要記下來**，之後設定 Google Cloud Console 時要填進「已授權的 JavaScript 來源」。

### 也可以直接在本機測試

直接用檔案總管點兩下 `index.html` 就會開。程式碼刻意沒用 ES module，就是為了讓這種開法能運作。

`file://` 和 GitHub Pages 是兩個不同的來源，資料各自獨立，所以本機測試不會動到網站上的資料。本機測不了的只有：連結批次開啟（彈出視窗的放行設定存不住），以及之後的 Drive 同步。加密功能在 `file://` 可以正常使用。

## 操作方式

### 常用語（主要工作區）

- **點整列任何位置** → 複製內容到剪貼簿，切到要用的視窗按 Ctrl+V
- **按複製鍵** → 每一條可自訂一個鍵（0～9、A～Z，可搭配 Alt），按下去直接複製那一條
- **編輯只能點右側的 ✎ 鉛筆**，會開彈窗改標籤與內容。刻意不做點文字就編輯，那會跟「點一下複製」搶同一塊區域
- 內容超過兩行會出現 `▾`，點了展開完整內容
- **拖曳每列最左邊的 ⠿ 把手可以調整順序**，常用的可以拉到最上面。只有把手能起拖，不會跟點擊複製打架
- 常用語卡片**橫跨整行寬度**，標籤欄固定寬、內容欄吃掉剩下的空間

### 複製鍵

在 ✎ 編輯彈窗裡設定，按「設定」然後直接按下想用的鍵就錄起來，不用自己打字。

- 可用範圍：`0`～`9`、`A`～`Z`，可搭配 Alt（例如 `Alt+A`）
- **留空代表不設**，那一條就只能用滑鼠點
- 同一分類內不可重複，錄製當下就會擋下並告訴你是哪一條佔用了
- 不分大小寫；不支援 Ctrl 和 Win 組合，那些多半已被瀏覽器占用
- **純字元的鍵在打字時不生效**（不然搜尋框沒辦法用），Alt 組合則不受影響

> 衝突範圍限在同一分類，不是全軟體——複製鍵只對畫面上看得到的卡片有意義，全軟體唯一的話鍵很快就不夠分。一個分類最多可以有 36 個。

### 卡片排序與釘選

- **拖曳卡片左上角的 ⠿ 把手**可以調整順序。只有把手能起拖，避免選字或點常用語時誤觸
- **☆ 釘選**：釘起來的卡片固定排在該分類最前面，☆ 變成實心 ★
- 上限是**同一分類、同一類型最多三個**。便籤釘滿不會吃掉常用語的額度，各類型分開算

### 連結收藏（批次開啟）

- 每一列前面有勾選框，上方有**全選／取消全選**，右邊是**開啟已勾選（N）**
- **一個項目可以放多條網址**（編輯彈窗裡一行一條），開啟時**隨機挑一條**。被封鎖不會自動換下一條
- 只填一條就是一般連結，行為跟以前一樣
- **單獨點名稱**照樣只開那一個，不受勾選狀態影響
- 勾選狀態不會存檔，只是「這次要開哪幾個」的暫時選擇
- **可以自己調順序**：滑鼠移到那一列，最左邊會浮出一顆 ⠿ 把手，按住拖到想要的位置。順序會存檔，跟著匯出匯入走。只能在同一張卡片裡排，搜尋中不給拖（畫面是過濾後的結果，拖出來的順序是錯的）
- **複製鈕**（✎ 左邊那顆）把網址複製到剪貼簿，要貼到別的地方時用得上。**一個項目有多條網址時固定複製第 1 條**——這跟「開啟時隨機挑一條」刻意不同，複製成功的訊息會寫明是第 1 條。小視窗裡也能用

> **一次開多個分頁需要先讓瀏覽器放行。** Chrome 預設只允許開第一個，其餘當成彈出式視窗擋掉。
>
> 被擋下時的完整說明**只會跳第一次**，之後只用一行小提示帶過。想再看說明，點連結卡片標題列上的圓形 **?** 鈕。
>
> 但這個設定是綁網址的，**用檔案總管直接開的 `file://` 可能存不住，這個功能請在 GitHub Pages 上使用。**

### 私人卡片（加密）

用來存需要保護的內容。**跟其他卡片不同，這張卡片的內容是真的加密過的**——存在瀏覽器裡的是密文，按 F12 也只看得到亂碼。

- **建議在 https 網址下使用。** 用檔案總管直接開的 `file://` 其實也能用（Chrome 把本機檔案視為安全環境，加密功能是在的），但正式使用請以 GitHub Pages 網址為準，那裡才存得住彈出視窗白名單、之後也才接得上 Drive 同步
- 萬一真的碰到不支援的環境（某些瀏覽器的 `http://` 頁面），卡片會顯示說明並停用，不會假裝有加密
- **新增時要先選「加密」或「不加密」**，沒有預設值。不加密的卡片內容是明文，任何能打開這個瀏覽器的人都看得到；標題列的圖示可以隨時互轉
- **每張加密卡片各自解鎖。** 輸入哪張卡片的密碼就只開哪張，其他張仍然隱藏著
- 第一次建立加密卡片時設定**主密碼**（長度不限，不只數字），系統會產生一組**復原金鑰**。之後新增的加密卡片沿用同一組主密碼，不會再產生新的復原金鑰
- **復原金鑰只出現一次**，忘記主密碼時是唯一的救援方式。請存在這個工具以外的地方
- 兩個都遺失就真的解不開了，只能全部刪除重來。這是加密的性質，不是設計限制
- 解鎖後**固定 10 分鐘自動隱藏**，計時不會因為操作而延長。標題列的 ⦿ 可以立刻隱藏
- **每一筆預設是摺疊的，只露出名稱**，左邊的 ▸ 點了才展開。這是多一層保護：路過的人瞄一眼只看得到你自己取的名字
- 摺疊狀態**不會被記住**。每次重新輸入主密碼進來，一律是全部摺疊，不會出現「上次展開的那筆還開著」
- 每一筆分兩種型別，新增時在彈窗最上面選：
  - **資訊**：名稱、網址、帳號、密碼、備註。帳號密碼各有複製鈕，密碼預設遮起來
  - **備忘錄**：名稱、網址、一整塊內容，展開後右下角有複製鈕
- **卡片上不標型別。** 兩種展開後長得不一樣，一眼就分得出來；標了反而等於幫人分類
- 有填網址的那一筆，名稱右邊會出現鏈條圖示，點了開新分頁
- **鎖住時不參與搜尋**，避免「搜得到就代表存在」洩漏資訊
- 有私人卡片時，**匯出資料前要先輸入主密碼**（匯出檔裡是密文）
- **刪除私人卡片、或刪除裡面的任何一筆，都要先輸入主密碼**（復原金鑰也可以），驗過了才會跳確認彈窗。驗證只是確認身分，不會把鎖著的卡片打開

標題列的小圓標預設寫「私人」，**點一下可以改成任何字**。這個標籤只是外觀、不是機密，所以鎖著也能改——用意是不讓卡片本身太顯眼。

### 外觀與顏色

**☰ →「外觀」**有兩個切換，改了立刻生效：

- **主題**：暗色（薰衣草紫）或亮色（奶茶色）
- **卡片上色**：細線（左邊一條色邊加小圓標）或滿版（整條標題列上色）

卡片的顏色**預設跟著類型走**：常用語綠、待辦霧藍、倒數粉、連結奶茶褐；便籤和私人卡片是中性、不上色。

- **想換某張卡片的顏色**：滑鼠移到卡片標題列，☆ 左邊會出現一個小色點，點下去選。最上面的「跟隨類型」可以恢復預設
- **分類貼紙的顏色**：滑鼠移到分類上點 `⋯`，選項最下面有一排色票
- 卡片和分類用同一組色票：綠、青、霧藍、粉、奶茶褐、可可（亮色主題是藕荷），加上中性
- 顏色跟著資料走，匯出匯入會一起帶著

> 自選顏色之後，類型要看小圓標上的字。例如把待辦改成粉色，乍看會像倒數。

### 自訂配色

**☰ →「外觀」→「自訂配色…」**，右邊會滑出調色面板，整頁往左縮但照樣看得到，改什麼立刻看到效果。

- **只調目前的主題**。在亮色打開就是調亮色，暗色完全不受影響；要調暗色，先到「外觀」切過去
- 每一項都能**點色塊用取色器**，或**直接輸入色碼**（`#4b9b75`、`4b9b75`、`#abc` 都可以）
- **基本配色**四項：底色、面板、文字、強調色。改一項，跟它有關的深淺會自動算好；沒改的維持原本的樣子
- **色票**：六個顏色，卡片與分類共用
- **進階**十項：選中分類的顏色、各種上色的濃淡、框線、刪除紅、預警琥珀、搜尋螢光
- **對比不夠時會標紅**並顯示比值，說明那個顏色用在哪裡；色票跟另一個太像時也會提醒。只是提醒，不會擋你
- 改過的項目名稱旁有 **●**，右邊 **↺** 單項恢復；最下面「**全部恢復預設**」
- 面板本身永遠用預設配色，就算把顏色調到看不見，面板還是讀得到、改得回來
- 自訂的顏色跟著資料走，匯出匯入會一起帶著

### 配色套組

自訂配色面板最上方有**三格套組**，可以依心情切換。每一格記住**整個外觀**：亮色或暗色、細線或滿版、所有自訂顏色。

- **點卡片**就套用，整個畫面一起換（包括亮暗）
- **「存到這格」**：把目前的外觀存進去。那一格已經存了別的配色時會先問要不要覆蓋；存回正在用的那一格則不問
- **✎**：改名（最多 12 字）或清除這一格
- 正在用的套組被調過、還沒存回去時，右上角會出現「**已修改**」
- 有調過但沒存的顏色時，換到別的套組前會先問一聲，免得心血白費
- **「預設亮色」「預設暗色」**：回到出廠顏色，不佔三格名額；細線或滿版維持你目前的設定
- **☰ →「外觀」**裡也有一排快速切換，不用打開面板就能換
- 套組跟著資料走，匯出匯入會一起帶著

### 倒數提醒

一張倒數卡片就是一份有日期的清單，**每一件事各自有自己的日期**，還可以選填時間。同一天的好幾件事會自動聚在一組，日期只寫一次；不同天的各自成組。

- 順序**自動依日期由近到遠**排，已過期的在最前面，已完成的沉到最後並淡化
- 日期那一行會接著寫「4 天後」「就是今天」「3 天前已過期」，不用自己心算
- **三天內轉琥珀、當天寫「就是今天」、過期轉紅**
- **新增任務會直接開彈窗**，一次填名稱、日期、時間，不用先生一列空白再回頭改
- 之後要改：**點文字改名稱，點右邊的時間標改日期與時間**。沒設時間的那個標平常藏著，滑鼠移到那一列才浮現
- **時間可以留空**，那就代表「那一天」，會在當天結束之後才算過期
- **日期也可以留空**，這種會集中在清單下方的「未定日期」一組

**分類貼紙上的小紅點**：某個分類裡有今天到期或已過期的未完成任務時，那張貼紙右邊會浮一顆小紅點，切在別的分類也察覺得到。滑鼠移上去時它會讓位給 ⋯。還有好幾天的不算，不然每個分類都掛著記號就等於沒有。

**關於提醒能做到什麼程度**：網頁沒辦法在關掉之後提醒你，那需要推播伺服器，這個工具沒有後端。所以提醒就是上面這些——顏色、天數、小紅點，前提是工具開著。想要更顯眼的話，把倒數卡片彈成置頂小視窗，它會一直浮在最上層。

日期加了時間之後，過期判定會跟著時鐘走：**到了那個時間點畫面會自己變紅**，不用重新整理。做法是算出下一次真的會有變化的時刻（某一筆到期、或午夜）只排那一個計時器，**沒有倒數卡片時一個計時器都不會排**；分頁切到背景也會停掉，切回來重算一次。

> **舊卡片**：原本卡片層級的那個日期，會在第一次載入時自動搬到所有還沒有自己日期的任務上，畫面看起來跟以前一樣。只有「有日期但一個子任務都沒有」的舊卡片救不回來——那個日期沒有地方可以去，程式不會憑空生一筆任務出來。重新建一張就好。

### 顯示大小

頂部列右邊、☰ 左邊有一顆「顯示大小」，點開可以選 80% 到 150% 七段。**整個畫面等比縮放**，字、按鈕、間距一起變，不會跑版。

覺得字太小就調大，這比去找瀏覽器的縮放功能好記。**設定會存起來**，下次打開還是你設的比例；跟著匯出匯入走，之後接上 Drive 同步就會跨裝置跟著你。

> 這跟瀏覽器自己的 Ctrl 加號是**相乘**的，兩個都調會疊加。覺得怪怪的就先把瀏覽器縮放按 Ctrl + 0 歸零。

置頂小視窗會套用同一個比例。

> 在編輯框或面板裡捲到底之後，**捲動會停在那裡**，不會繼續把背後的卡片區一起捲走。

### 卡片怎麼排

卡片區是**密集排版**：一張很長的卡片不會把旁邊的卡片整排往下推，短卡片會直接貼在上一張底下。

卡片的先後順序還是你拖出來的，由左到右、由上到下填，只是縱向的空隙被壓掉了。

**唯一的例外是常用語卡**。它橫跨整行，所以會把畫面切成上下兩段，它上面和下面的卡片不會互相咬合。這是「佔滿整行」的必然結果——要解掉就得讓常用語不橫跨，那會回到內容欄只剩兩三個字寬的老問題。

### 編碼卡

一張填表格的卡片：上面選一選、貼一貼，下面就出來可以直接複製的東西。**卡片出廠是空的，所有內容都是你自己建的。**

**先設定一次**

兩組選項各有一顆「管理」，點進去新增：

> **管理視窗會一直開著**：編輯、新增、刪除一個選項之後都會回到清單，可以一口氣改好幾個，按「關閉」才真的關掉。

> **順序可以調**：按住每一列左邊的 ⠿ 往上或往下拖，放開就換位置。調好的順序就是卡片上那一排按鈕的排列順序，跟著資料檔走。編碼卡的兩組、表單卡的類別（單向與雙向各一份）與附註都可以這樣調，**只能在同一組之內排序**。

- **第一組**（預設叫「項目」）：每個選項有**名稱**和一段**文案**。選到哪一個，就產生那一段
- **第二組**（預設叫「方式」）：每個選項只有名稱，加上兩個開關
  - **這個選項不需要來源字串**：勾了之後不會出現貼上欄，隨機碼改成長版（四碼加八位數字），本身就是完整結果
  - **結果一定要有數字**：取到的尾段全是英文字母時，把隨機碼的最後一碼換成數字，確保結果裡至少有一個數字

文案裡可以用三種記號：

| 記號 | 意思 |
|---|---|
| `【代碼】` | 換成這一次的隨機碼 |
| `【方式】` | 換成第二組選到的那個名稱 |
| `〔…〕` | 括起來的段落，選到「不需要來源字串」的選項時**整段消失** |

舉例（**用中性的假字，不要照抄成你的實際用語**）：文案寫「甲的結果為【代碼】〔接上【方式】的尾段〕」。選了需要貼來源的選項，出來是「甲的結果為 QXab 接上 類型一 的尾段」；選了不需要來源的選項，出來是「甲的結果為 QXab12345678」，括號那段自己不見。

**每天怎麼用**

1. 上面兩組各點一個
2. 貼上完整資訊（**自動只取尾段**，整串貼進去就好，不必自己剪）
3. 下面「產出」框出現結果與文案
4. **文案點一下就複製**；**結果要按旁邊的複製鈕**——那是機敏的東西，不讓你滑過去就帶走
5. 想換一組隨機碼按 🔄，文案與結果會一起跟著換

文案下面有一行「↑ 點一下就複製」的提示，因為那一塊沒有按鈕，不講你不會知道它可以點。

**所有標籤都可以改字，而且清空就回到出廠的字**。那些預設字（來源、對象、數值、類別…）是中性的，久沒用這張卡片時可以靠它認出每一欄原本是幹嘛的——所以名稱刪掉不會留下空白，會自動變回預設。

**所有標籤都可以改字**：兩個框的標題（填寫／產出）、兩組的組名、來源那一行、結果那一行，點一下就能改。來源那一行的標籤是**樣板**，裡面寫 `【方式】` 的話會跟著你選的選項變（例如標籤寫成「【方式】的尾段」、選了「類型一」，就顯示「類型一的尾段」）。

> **出廠的預設字一律是中性的。** 來源那一欄預設就叫「貼上完整資訊」，輸入框裡的淡字也是同一句——它是程式裡的字，不存進你的資料檔，所以之後改了程式，你的卡片會直接跟著換。**如果你自己改過那個標籤，改過的字是你的資料，不會被動到**；要回到預設就把它清空。

**不會留下任何痕跡**：貼上的字串、產生的結果、選到的選項**都不寫進資料檔，也不進匯出檔**，重新整理就回到空白。存起來的只有你的設定（選項、文案、標籤）。

> **為什麼卡片裡的預設字那麼中性**：程式碼在公開的儲存庫上，任何人都看得到。所以程式只放機制（產生隨機碼、取字串尾段、代入模板），你的用語與句子全部是資料，存在你自己的瀏覽器裡。要分享給別人就用「☰ → 匯出資料」私下傳檔案給他們，**絕對不要把匯出檔放進儲存庫**。

### 表單卡

跟編碼卡同一個想法：**卡片出廠是空的，格式與名詞都是你自己定的。**

**先設定一次**

從卡片的 **⋯ → 輸出格式**，兩個模式**各寫一欄**，把最後要複製的樣子整個寫出來。程式不會替你重複任何東西——你寫幾行就出幾行。

第一個模式（預設叫「雙向」）會產生兩段，可以用的記號是 `【來源】`、`【對象A】`、`【對象B】`、`【類別A】`、`【類別B】`、`【數值】`。兩段的對象與類別各有自己的記號，所以你直接把兩段都寫出來，中間要空幾行、要不要標題行、備註寫 `-` 還是別的，全部自己決定。

第二個模式（預設叫「單向」）只有一段，可以用的記號是 `【來源】`、`【對象】`、`【類別】`、`【數值】`、`【附註】`。

兩個模式的**名稱**點模式那排的「管理」就能改（只能改名，不能增減——一個會產生兩段、一個一段，欄位也不一樣，那是寫在程式裡的）。

再來是兩組選項，各有一顆「管理」：

- **類別**：**兩個模式各有一份自己的清單，互不影響**——在單向那排新增、改名、刪掉一個選項，雙向那排不會跟著動
  - 第一個模式（雙向）的選項：名稱、**前段顯示成**、**後段顯示成**（留空就用名稱，對應 `【類別A】`、`【類別B】`）、**附加句**（選到這個類別時接在最後面的一行，不填就沒有）
  - 第二個模式（單向）的選項：名稱、**顯示成**（只有一格，因為只有一段；留空就用名稱，對應 `【類別】`）、**附加句**
  - 那一排上面的**標籤字也是各自一份**，出廠都是「類別」，改一邊不會動到另一邊
- **附註**（只有第二個模式會用到）：名稱、內容（留空就用名稱本身）

> **同一個選項要在產出裡顯示成別的字，就填「顯示成」。** 例如選項叫甲、但產出那行要寫乙，把「顯示成」填乙就好——這些字都只存在你的瀏覽器裡，不會進程式碼。

**附註選項變多時可以整排收起來**：「附註」那一行前面有一顆 ▾，點一下把整排選項收掉，只剩標籤與數量（例如「附註（12）」），要選的時候再展開。**收合狀態跟著資料檔走**，換電腦、匯出匯入都記得。收的只是選項那一排，底下的附註輸入欄照樣在。置頂小視窗一律當成展開——彈出來就是要用它。

**每天怎麼用**

1. 選模式，欄位與選項都會跟著換——第一個模式有兩個對象欄，第二個有一個對象欄加附註；那一排選項也換成該模式自己那份
2. 填欄位、選一個類別（兩個模式選到的是各自那份，切過去不會互相蓋掉）
3. 下面「產出」框出現整段文字，**點一下就複製**
4. 單向的附註可以點選項快速填入，**填進去之後還能自己改字**
5. 「一鍵清空」只清輸入欄，模式與選到的類別不動

**哪些欄位是必填的，由你的模板決定**：模板裡用到哪個記號，那一欄才必填。沒填完的時候產出框會告訴你還缺什麼。

**標籤全部可以改字，清空就回到出廠的中性字**（來源、對象 A、數值、類別…）。久沒用這張卡片時，把名稱刪掉就能看到那一欄原本是幹嘛的。

跟編碼卡一樣，**填進去的值都不存**，重新整理就回到空白；存起來的只有你的設定。

### 卡片收合

卡片太多要捲很久的時候，**點標題列的 ▾ 把那張卡片收成一條**，再點 ▸ 打開。

- **收合狀態會記住**，跟著匯出匯入走，換電腦也一樣
- 想一次收掉一整個分類：**分類的 ⋯ →「全部收合」**（都收起來時那一項會變成「全部展開」）
- **搜尋時一律當成展開**。搜尋出來的卡片收著等於找到了卻看不到，所以搜尋期間自動打開，清掉搜尋就恢復原狀
- **收合的倒數卡片如果還有今天到期或已過期的事，標題列上會浮一顆小紅點**，跟側欄那顆同一個意思。收起來不會把提醒一起關掉
- **收合的卡片，裡面的複製鍵一併停用**。收合的意思就是「這張現在不用」，按鍵不會去動看不到的內容；展開就恢復。注意複製鍵的唯一性還是以整個分類為準，收起來不會把那個鍵讓出去給別張用
- **置頂小視窗不受收合影響**——彈出來就是要看那張卡片的內容
- 收合一張卡片之後，旁邊的卡片會往上遞補。那是密集排版的必然結果，不是壞掉

> 為什麼不是「點標題列就收合」：標題文字點下去是改標題，私人卡片的小圓標點下去是改字。同一塊地方再多一個收合的意思，就會變成想改標題卻收了卡片。所以收合只認那一顆 ▾。

### 便籤

**一張便籤卡可以放很多筆**，不用為了記三件事開三張卡。

- 每一筆可以**各自摺疊展開**，摺疊時顯示內容的第一行
- 右邊只有展開鈕與刪除鈕，按住 ⠿ 可以調整順序。**刻意沒有複製鈕**——一筆一顆會讓標題列擠成一排符號，要複製就點進去選取
- ⋯ 選單裡有「全部收合／全部展開」
- **展開狀態會記住**，跟著匯出匯入走，下次打開還是你離開時的樣子
- 內容維持**點文字就能改**。多行內容進入編輯時**不會全選**，游標放在最後面——全選的狀態下隨便按一個鍵就整段沒了

**編輯框拉大之後的高度會記住，而且顯示狀態也會套用同一個高度。**（編輯中不套用上限，不然你拉大編輯框只會變成在裡面捲動。） 所以一段很長的內容不會把卡片撐成一整頁，超過的部分在那一筆裡面捲動。整張卡片共用一個高度，拉一次就好。

> 舊的單段便籤會自動轉成第一筆，內容一個字都不會掉。

### 置頂小視窗

點卡片標題列的彈出鈕，那張卡片會變成一個**浮在所有視窗最上層**的小視窗。其他視窗擋在前面也看得到、點得到，這是瀏覽器版唯一能做出常駐最上層的辦法。

- **只有 Chrome、Edge 這類 Chromium 瀏覽器支援。** 不支援時彈出鈕不會出現，⋯ 選單裡會有一個停用的項目說明原因（下面那個「不置頂」的版本任何瀏覽器都能開）
- **同時只能開一個。** 這是瀏覽器的限制，不是沒做。點另一張卡片的彈出鈕就是換內容
- **視窗位置沒辦法指定**，由瀏覽器決定；**大小會記住**，下次開就是上次的尺寸
- 主視窗改了內容或換了主題，小視窗即時跟著變

#### 不想讓它一直蓋在最上面：⋯ →「彈出成不置頂視窗」

同一張卡片也可以彈成**普通的視窗**，內容與唯讀規則一模一樣，差別只有它**會被其他視窗蓋住**。

- 「浮在最上層」是置頂小視窗規範裡寫死的行為，沒有開關可以關掉，所以不置頂用的是另一種視窗
- 因為是普通視窗，**任何瀏覽器都開得出來**；但有可能被「彈出式視窗」的封鎖擋掉，擋掉時會跳提示，在網址列右邊允許之後再試一次
- **小視窗右上角有一顆圖釘**，可以當場在置頂與不置頂之間換，顯示的卡片與填進去的值都不會掉
- **預設是置頂**，而且不記住上次的選擇——標題列常駐的那顆彈出鈕永遠是置頂那一種
- 同時仍然只留一個小視窗，不論哪一種
- 主視窗重新整理或關掉時，不置頂視窗會一起收掉（它不像置頂視窗會自己跟著消失）

**小視窗裡是唯讀的**：看得到、點一下複製、待辦可以勾，但編輯、新增、刪除、拖曳、選色都不出現。空間小，誤觸的代價比在主視窗高。要改內容回主視窗改，小視窗會立刻同步。

**例外是編碼卡與表單卡**：這兩張在小視窗裡**可以填寫**——選選項、貼字串、打欄位、換一個隨機碼、一鍵清空、複製結果都能用。它們本來就是「當場產生一段字拿去貼」的工具，彈出來卻不能用就沒有意義了。**設定仍然只能在主視窗改**：管理選項、輸出格式、標籤改字在小視窗裡都不出現。

> **一個要知道的落差**：小視窗跟主視窗共用同一份暫存值，但畫面不會即時互相更新。在小視窗填完，主視窗那張卡片要等下一次重畫才會跟上（看起來像空的），反過來也一樣。填進去的值本來就不存檔，重新整理就沒了。

**複製鍵在小視窗裡一樣有效**，按下去複製的是小視窗裡那張卡片的內容。

**加密的私人卡片也可以彈出來**，而且可以直接在小視窗裡輸入主密碼解鎖——主視窗的密碼框這時多半被其他視窗蓋住了，所以那個輸入框是另外做在小視窗裡的。

解鎖之後多一層保護：**小視窗一失去焦點（例如你切去其他視窗打字），展開的項目會自動收回去**，只剩名稱清單。卡片本身沒有重新上鎖，回來點一下就展開，不必重打密碼。這是因為小視窗會一直浮在最上層，原本「切走就被蓋住」那層保護不存在了。

### 彈窗的關閉方式

**編輯類彈窗只能用「取消」或「儲存」關閉。** 點背景、按 Esc 都不會關，避免打到一半誤觸就整批消失。

適用於：編輯常用語、編輯連結、新增／改名分類、新增卡片標題。

唯讀類彈窗（關於、外觀、分類選項、刪除確認、卡片類型選擇）按 Esc 仍可關閉，那些沒有會遺失的內容。卡片的選色小視窗點外面就會關。

> 卡片標題、便籤、待辦的**就地編輯**不受影響——那些點到別處是**存檔**，不是丟棄。

### 搜尋

頂部搜尋框比對卡片標題、常用語的標籤與內容、便籤內容、待辦項目。

**搜尋命中的字會被標起來**（顏色可以在自訂配色的「搜尋螢光」裡調）。

**搜尋範圍是全部分類**，不是只有現在選中的那一個。結果會依分類分組，每一組上面一行分類名稱，這樣才看得出命中的卡片是哪個分類的。

**打簡體找得到繁體，打繁體也找得到簡體。** 例如打「头发」會找到「頭髮」、打「电脑」會找到「電腦」。比對的時候兩邊都會先折成簡體，所以不論你的內容是哪一種寫法都搜得到。

搜尋時有三個地方跟平常不同：

- **複製鍵撞號的會暫時失效**。複製鍵的唯一範圍是分類，跨分類看到兩張卡片都綁同一個鍵時，按下去無法判斷該複製哪一條，所以那幾條一起停用。清掉搜尋就恢復
- **不能拖曳排序**。畫面上是過濾後的結果，這時候拖出來的順序是錯的，所以拖曳把手不會出現
- **不能新增卡片**。看不出會加到哪個分類，先清掉搜尋再新增

**點側欄的分類會順手清掉搜尋**，因為點分類的意思就是「我要去那裡」。

鎖住的加密私人卡片完全不參與搜尋，密碼欄位任何情況下都不參與。

### 把卡片搬到其他分類

兩種做法，結果一樣：

- **拖**：按住卡片標題列的 ⠿ 把手，拖到左邊的分類上放開
- **點**：卡片標題列的 **⋯** → 「移到其他分類」，從清單挑一個

搬過去之後卡片會排在那個分類的最後面，畫面留在原來的分類。兩種情況會順手幫你處理掉並在提示裡講：

- 目標分類的**同類型釘選已經滿三個**，搬過去的那張會自動取消釘選
- 常用語的**複製鍵跟目標分類重複**，重複的那幾條會被清空（原分類的卡片一個都不動），搬完再重新設定就好

### 最近刪除

**刪掉的卡片與分類不會馬上消失**，會先進保留區，**保留 2 天、最多 30 筆**，兩個條件哪個先到都算數（滿了就把最舊的擠掉）。

從 **☰ → 最近刪除**打開，每一筆寫著名稱、是什麼、原本在哪個分類、什麼時候刪的：

- **還原**：放回原分類。原分類已經被刪掉的話，會放到你目前所在的分類，提示會告訴你
- **✕**：那一筆永久刪除（要二次確認）
- **全部清空**：整個保留區清掉（要二次確認）

跟選項管理一樣，做完一筆會**回到清單**，按「關閉」才真的關掉。

**收進保留區的只有「整張卡片」與「整個分類」**，還有「清除分類內容」清掉的那一批。卡片裡的單一一筆（一條常用語、一則便籤、一個待辦）**不收**——那些重打的成本低，收進來反而讓保留區很快被佔滿。

保留區**跟著匯出檔走**，所以換電腦匯入之後照樣還原得了。

> **加密的私人卡片**：清單裡只看得到標題，內容仍然是密文。還原不必再驗一次身分——還原回來它照樣是鎖著的，不會因此看到任何內容。另外，只要保留區裡還有加密卡片，主密碼就不會被清掉，不然還原回來會是一張永遠打不開的殼。

### 雲端同步（Google Drive）

頂部列那顆雲朵圖示就是同步。旁邊的小點是狀態：**綠**＝已同步、**琥珀**＝還沒登入或正在同步、**紅**＝同步失敗。滑鼠移上去看得到完整說明，點一下開面板（帳號、立刻同步、登出）。

- **雲端才是資料真正保存的地方。** 這個分頁的暫存區關掉就清了，所以**開始輸入內容之前請先登入**
- **登入不會硬跳授權視窗**。第一次要自己按「登入 Google」；同一個分頁重新整理之後會**自動在背景把權杖拿回來**（不跳任何視窗），資料自己回來
- 拿不回來的時候（Google 那邊的登入狀態掉了、瀏覽器擋第三方 cookie）才顯示登入鈕，訊息會寫清楚是哪一種原因
- **按登入時先試靜默**，早就授權過的話通常不會跳「選擇帳戶」畫面，點一下就好
- 權杖只有一小時，**到期前五分鐘會自己換一張**，不會等到要同步時才發現過期
- 權杖**只放在記憶體**，不寫進瀏覽器——不然等於把鑰匙留在那台電腦上
- 資料存成你自己雲端硬碟裡的**隱藏資料夾**的一個檔案，在雲端硬碟的畫面上看不到，別的應用程式也讀不到
- **分頁暫存照舊 1 秒存一次；雲端是停手 10 秒才上傳**，關掉分頁前會補傳一次
- **不會自己去雲端抓新的**。另一台改過的東西，這台要重新整理或按「立刻同步」才拿得到

#### 登出會把這個分頁的資料一起清掉

這是為了公用電腦：只斷開雲端、把內容留在瀏覽器裡等於沒有保護。

- 登出流程是**先把沒上傳的變更傳完，才清掉本機的東西**
- 傳不上去（離線、上傳失敗）時**會先問你**，並給一顆「先匯出這台的資料留底」
- **關掉分頁也一樣會清**，不必記得按登出
- 雲端那一份不會被刪，下次登入同一個帳號就拉回來

#### 以雲端為主，不再每次問

| 情況 | 會發生什麼 |
|---|---|
| 登入時這個分頁是空的（新分頁、剛登出） | 直接把雲端那份拉下來 |
| 你在這台改東西 | 停手 10 秒上傳 |
| 這台沒有還沒上傳的東西，雲端卻不一樣（另一台改過） | **直接以雲端為準覆蓋這台**，不問 |
| 這台有還沒上傳的東西，雲端也動過 | **問一次**，列出兩邊時間讓你選 |

> 「直接覆蓋不問」是刻意選的：多數時候你要的就是最新那份。代價是極端情況（改完十秒內斷電、記號沒寫進去）那幾筆會安靜消失，所以重要的東西打完可以按一下「立刻同步」。

#### 兩邊都改過的時候

會跳一個彈窗，列出兩邊各自的最後修改時間，讓你選**用這台的**或**用雲端的**，另外附一顆「先匯出這台的資料留底」。

**程式不會自動合併。** 合併聽起來聰明，但合錯的時候你沒辦法還原。

#### 幾件要知道的事

- **加密的私人卡片上傳的是密文**，主密碼和解開後的內容永遠不會離開這台電腦
- **不加密的卡片在雲端是明文**（只有你的帳號進得去，但性質跟只存在本機不一樣）
- **同步解決不了容量上限**：資料要先存得進瀏覽器才談得上同步
- 離線時照常用，那個點會變琥珀，恢復連線後自動補傳

### 儲存空間

**☰ 選單最下面有一條儲存空間**，寫著目前用掉幾 %，滑鼠移上去看得到實際大小（例如「1.9 MB／5.0 MB」）。

- 上限是瀏覽器給的 **5,242,880 個字**（實測值，中文與英文各算一個）
- 算的是**這個分頁**用掉多少。分頁暫存每個分頁各自一份，跟其他分頁、其他專案分開算
- **超過 80% 條子轉琥珀、95% 轉紅**，並且跳一次提醒（每次開啟頁面只跳一次）。提醒裡會**直接列出目前最佔空間的幾張卡片**與各自的大小，不必自己一張張猜
- **滿了怎麼辦的完整步驟寫在 ☰ →「關於／說明」裡**，隨時查得到：先匯出留底 → 清空最近刪除 → 找出真正大的東西（通常是貼進便籤的長文件）→ 最後手段是匯出、關掉分頁重開、再匯入

### 資料沒存進去的時候

瀏覽器給每個分頁的暫存空間大約 5MB。滿了、或瀏覽器設定擋掉網站資料時，**寫入會失敗**。

以前失敗是完全安靜的（只在 F12 主控台印一行），你會以為存好了。現在會**跳出說明**，講清楚發生什麼事、常見原因，以及照什麼順序處理（先匯出留底 → 清空最近刪除 → 刪掉用不到的卡片 → 確認瀏覽器沒有擋掉網站資料）。

**跳出訊息時畫面上的內容仍然是完整的**，所以第一步一定是先「匯出資料」把它存成檔案。

### 其他

- 待辦：沒有複製行為，所以維持**點文字就能改**。勾完的項目**不會自動沉底**，順序照你排的；下方有「清除已完成（N）」可以一次刪掉，會先跳確認。倒數卡片也有同一顆按鈕
- 倒數提醒：見下面「倒數提醒」那一節
- 多行內容：**Ctrl+Enter 存檔**，直接按 Enter 是換行
- 分類貼紙可以**拖曳排序**，滑鼠移上去會出現 `⋯` 開選項
- **所有 ✕ 刪除都會跳確認視窗**：卡片、常用語、待辦項目、連結，一個都不例外

## 資料存在哪（這一版改了，請讀完）

**資料放在「這個分頁的暫存區」，關掉分頁就清掉，登出也會清掉。** 真正長期保存的地方是**雲端同步**。

| 動作 | 資料還在嗎 |
|---|---|
| 同一個分頁按 F5 重新整理 | **還在**（而且不需要網路） |
| 斷線 | **還在**，恢復連線自動補傳 |
| 關掉分頁或整個瀏覽器視窗 | **清掉** |
| 按登出 | **清掉**（沒上傳的東西會先問你） |
| 換電腦、重開機、公司電腦還原 | 本機當然沒有了，但**登入同一個 Google 帳號就拉回來** |

**為什麼這樣做**：公用電腦上不能留下你的內容，而「記得按登出」靠不住。關掉分頁就沒了，才是真的不留痕跡。

**代價**：**不登入就等於一張空白工具**。沒登入時打的東西，關掉分頁就沒了。所以：

1. **開始輸入內容之前先登入雲端**
2. 連不上 Google（斷線、Google 進不去）時還有一條路：**☰ → 匯入資料**，用之前的備份檔臨時用一下（同樣只存在這個分頁）
3. 匯出檔仍然是最後一道保險——雲端那份是跟著你改的，**誤刪也會同步過去**

> **從舊版升級的人**：原本存在瀏覽器裡的資料會在第一次打開新版時**自動搬進分頁暫存**，並跳一個說明。舊的那份會從瀏覽器裡刪掉（公用電腦上不留痕）。搬完請先登入雲端，或匯出一份留底。

> **如果瀏覽器連分頁暫存都不給用**（某些設定），工具還是能用，但資料只在記憶體裡、重新整理就沒了。開啟時會跳一行提示告訴你。

## 資料格式

內部格式是 camelCase，最外層長這樣：

```json
{
  "version": 2,
  "updatedAt": "ISO 時間",
  "appTitle": "便籤／常用語",
  "settings": { "autoLockEnabled": false, "autoLockMinutes": 30,
                "theme": { "mode": "dark", "cardStyle": "line" } },
  "categories": [ { "id": "", "name": "", "shortLabel": "", "order": 0, "color": null } ],
  "tabs": [ { "id": "", "categoryId": "", "type": "quickphrase", "title": "", "order": 0,
              "collapsed": false, "color": null, "rows": [] } ]
  // 編碼卡另有 labels（欄位標籤）、g1（選項與文案）、g2（選項與兩個開關）
  // 表單卡另有 labels、tplTwo／tplOne（兩個模式各自的輸出模板）、
  //           cats（雙向那份選項）、catsOne（單向那份選項）、notes（附註選項）
}
```

`color` 存的是色票名稱（例如 `"teal"`），不是色碼，這樣切換亮暗主題時才能自動換成對應的版本。卡片的 `null` 代表跟隨類型。

### 匯入相容性

匯入時會自動辨識三種格式：

1. **本版格式**（camelCase）
2. **桌面版 WPF 實際存檔**（PascalCase、`Categories` / `Tabs`、`Tabs` 底下用 `type` 區分類型）
3. **v1.3 規格書第 9 章的草案格式**（camelCase，但 `quickPhrases` 獨立成陣列、用 `tabId` 掛回卡片）

> 格式 2 和 3 其實不一樣——舊規格書的草案跟桌面版實際實作對不上。兩種都吃進來，以防萬一。

匯入桌面版資料時，這些欄位會被丟掉（瀏覽器版沒有對應功能）：
`PickerHotkey`、`PinnedWindowTitle`、`PinnedWindowProcess`、`PanelOpacity`、
`Rows[].Hotkey`、`Categories[].IsQuickPhraseZone`、`Tabs[].Mode`

## 已知限制

- **小視窗的剪貼簿沒辦法在開發環境測**（沙盒沒有系統剪貼簿）。程式裡寫了兩條路：先試瀏覽器的剪貼簿 API，失敗就走舊版的備援方式，兩條都發生在小視窗自己的文件上。**第一次用請實際貼一次確認**
- **剪貼簿一定會被覆蓋**。這是改用剪貼簿機制的必然代價，桌面版原本刻意避開這點，瀏覽器做不到
- **複製鍵不是全域熱鍵**，網頁沒有焦點時無效。這是瀏覽器沙盒的硬限制
- **搜尋時不能拖曳排序，也不能新增卡片**。原因見上面的搜尋說明
- **倒數任務不能手動排序**，一律依日期自動排。日期就是它的順序
- **釘選的卡片永遠在最前面**，所以把已釘選的卡片拖到未釘選的區域，它只會停在釘選區的最後一個位置，不會真的跑下去
- 釘選目前只做**置頂排序**。之後的置頂小視窗（PiP）要不要沿用這個標記，等小視窗做出來看實際效果再決定
- **置頂小視窗同時只能開一個**，做不到同時拉出好幾張卡片。視窗位置也沒辦法指定
- **批次開啟的分頁沒辦法自動分組**。Chrome 的分頁群組只有擴充功能能操作，一般網頁碰不到
- **簡繁互轉只做逐字對應，不換詞彙**。打「头发」找得到「頭髮」，但打「鼠标」找不到「滑鼠」。這是刻意的：詞彙轉換會把「記憶體」整個換成別的詞，打一半的「記憶」就比不到了，而搜尋幾乎都是打一半
- **字典是第一次搜尋時才下載的**（109 KB）。系統還原後瀏覽器快取被清掉，當天第一次搜尋會重新下載一次，之後就有快取。萬一下載不到（例如網路不通），搜尋會自動退回原字比對，功能不會壞，只是簡繁不互通
- **除了加密的私人卡片以外，分頁暫存裡都是明文**，按 F12 就讀得到。需要保護的內容請放進加密的私人卡片

## 測試過的部分

- 五個 JS 檔通過 Node 語法檢查，HTML 通過 parser 檢查
- 交叉比對：`getElementById` 目標、JS 用到的 CSS class、各模組的函式呼叫都有對應實作；樣式表裡沒有寫死的顏色，暗色與亮色兩套變數名稱一致
- **單雙向清單分家實測（v4.16）**：兩個模式各有一份選項清單、互相看不到對方的選項、選到哪一個也各記一份；單向的選項只有一格「顯示成」（留空用名稱），附加句照樣接在最後；那一排的標籤字各自獨立，改單向不會動到雙向；管理彈窗只列出該模式自己那份；舊資料自動複製一份給單向當起點（顯示成留空，所以產出跟拆開前一模一樣）；匯出匯入往返、竄改過的欄位一律丟掉
- **小調整（v4.17）**：「換一個」改成自繪 SVG（emoji 在不同系統會被換成各自的彩色圖案，大小與顏色都不受控）；選項編輯視窗的說明只留框裡的淡字，不在框下面再寫一次同樣的話。另外確認過搜尋框不必自己做清除鈕——`type="search"` 瀏覽器本來就有一顆
- **儲存空間實測（v4.17）**：選單裡的容量條、百分比與實際大小、用量不多時不標色、超過門檻換色並提醒一次、提醒裡列出最佔空間的卡片、卡片名稱含角括號時不會被當成 HTML、同一次開頁不重複提醒、算的是整個網址下的全部資料（別的專案佔的空間也算進去）
